## 아키텍처 불변조건

1. 코드 작성·수정·테스트는 Antigravity에서 수행한다.
2. SUMMED의 AI 실행 엔진은 ChatGPT 구독 계정으로 로그인된 로컬 Codex CLI다.
3. OpenAI API와 API 키 기반 과금은 사용하지 않는다.
4. 앱에서 `codex exec`를 호출하고 구조화된 결과를 검증한다.
5. 사용자 Codex 인증정보를 프로젝트에 복사하거나 저장하지 않는다.
6. 앱은 사용자의 신뢰할 수 있는 로컬 환경에서 실행한다.
7. 재개할 때 `SUMMED.md`와 최신 인계 문서를 먼저 읽는다.

## 내린 결정과 근거

- 불변조건은 인계 문서에만 두지 않고 루트 `AGENTS.md`에 기록했다. 새 에이전트와 새 세션에도 자동 적용돼야 하는 프로젝트 수준 규칙이기 때문이다.
- 인증은 사용자가 이미 로그인한 로컬 Codex CLI에 위임한다. 프로젝트가 인증정보를 소유하거나 API 키 과금을 유발하지 않게 하기 위함이다.
- 신뢰할 수 있는 단일 사용자 로컬 앱이라는 운영 전제를 유지한다. 현재 파일·Drive·Codex 통합 구조의 보안 경계이기 때문이다.
